# Unauthorised samples

Put a photo and a voice recording of someone **outside the team** here (with
their permission), in any format, for example `stranger_face.jpg` and
`stranger_voice.m4a`. Ideally record the voice on one of the team's own phones,
so the test is about the voice and not the device.

`python app.py --demo` uses the first photo and the first recording in this
folder for the unauthorised-attempt scenarios. While the folder has no samples,
the demo simulates a stranger instead by enrolling the team without one member.

Files here are never used for training.
